## 🎨 Architectural Standards & Design System

Engineered under the rigorous standards of three foundational open-source design skills:

1. **Hallmark (Nutlope/hallmark)**:
   - Token architecture (`:root` CSS custom properties) across surfaces, text, and borders.
   - Non-waivable Floor quality gates: zero `transition: all`, accessible focus states (`:focus-visible`), and responsive layouts with zero horizontal scroll.
   - Elimination of AI slop tropes (no fake metrics, no repetitive boxed cards, no ungrounded gradients).
2. **Impeccable (pbakaus/impeccable)**:
   - High-craft typography (`Barlow Condensed` display, `Manrope` body, `JetBrains Mono` code).
   - Documented contracts: [`DESIGN.md`](./DESIGN.md) and [`PRODUCT.md`](./PRODUCT.md).
   - Strict WCAG AA contrast (≥4.5:1 text contrast).
3. **Taste Skill (Leonxlnx/taste-skill)**:
   - Editorial minimalism, deliberate negative space, and curated visual hierarchy.
   - Motion budget: physical easing curves and tight transition durations.

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/Arshad9999/my-portfolio-site.git
cd my-portfolio-site

# Run a local web server
python3 -m http.server 8080
```

Open [http://localhost:8080](http://localhost:8080) in your browser.
